# bunker-tributsa
VR-проект Бункер Трибуца

Лендинг проекта — статические HTML/CSS/JS без сборки и зависимостей.

* `index.html` — разметка всех 10 блоков
* `assets/css/style.css` — стили, эффекты плёнки, туман, адаптив
* `assets/js/main.js` — параллакс «Спуска», маяк, частицы, модальные окна героев
* `media/` — исходные медиафайлы (см. `bunker-tributsa-design-brief.md`)

Локальный просмотр: `python3 -m http.server` в корне репозитория и открыть http://localhost:8000.
Для публикации подходит GitHub Pages (ветка, корень репозитория).

## Медиафайлы

Исходники лежат в `media/`, а сайт показывает их облегчённые копии из `assets/media/`
(картинки в WebP, трейлер перекодирован). После замены файла в `media/` пересоберите копии:

```
python3 tools/optimize_media.py
```
